# 🧠 GenAI App with Docker & Hugging Face

This is a simple Generative AI (GenAI) web application that uses a Hugging Face model for text generation and runs inside a Docker container. It provides a user-friendly interface using Gradio.

## 🚀 Features

- Text generation using Hugging Face's `google/flan-t5-small` model
- Clean and responsive Gradio UI
- Fully containerized using Docker for easy deployment
- Lightweight and minimal setup

## 🛠️ Tech Stack

- Python
- Hugging Face Transformers
- Gradio
- Docker
